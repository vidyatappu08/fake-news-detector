```markdown
# NewsCheck AI

NewsCheck AI is a machine learning–powered application that helps users identify whether a news article is **real** or **fake**.  
It analyzes text input using a trained ML model and provides an instant prediction with accuracy.

## 🚀 Features
- Detects **fake vs real** news instantly  
- Simple and clean UI  
- Fast prediction using `model.pkl`  
- Built using lightweight Python tools  


## 🛠 Tech Stack
- **Python**
- **Flask / Streamlit**
- **Pandas**
- **Scikit-learn**
- **Trained ML Model:** `model.pkl`

## 📂 Project Structure
```
├── app.py
├── model.pkl
├── requirements.txt
├── templates/
└── static/


## ▶️ Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/vidyatappu08/fake-news-detector.git
````

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the app

For Streamlit:

```bash
streamlit run app.py
```

For Flask:

```bash
python app.py
```

## 📊 Model Information

The ML model was trained using a labeled dataset of fake and real news.
The text data was cleaned, transformed, and vectorized before training.
